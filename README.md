# 📊 منصة وداشبورد المبيعات والتنفيذ (Sales & Delivery Dashboard) - الإصدار 2.0

داشبورد متكامل وحديث لإدارة عمليات المبيعات، إسناد وتوزيع العملاء المحتملين بدقة، ومتابعة مشاريع التنفيذ بين الأقسام، جاهز تماماً للرفع المباشر على **Vercel** والعمل بكفاءة عالية.

---

## 🌟 أبرز التحديثات والمميزات الجديدة

### 1. 🎯 إسناد وتعيين عملاء محددين بعينهم (الطلب الأساسي)
- **مربعات تحديد (Checkboxes)** لكل عميل في جدول المبيعات.
- **تحديد / إلغاء تحديد الكل** بضغطة واحدة من رأس الجدول.
- **شريط إجراءات عائم (Floating Action Dock)** يظهر في الأسفل فور تحديد أي عميل:
  - يعرض عدد العملاء المحددين بدقة (مثل: `تم تحديد 5 عملاء`).
  - اختيار مسؤول المبيعات (السيلز) من القائمة المنسدلة.
  - زر **⚡ إسناد المحددين** مع رسالة تأكيد لحماية البيانات من الخطأ.
  - زر **إلغاء تعيين المحددين** لتحويلهم إلى غير معيّنين فوراً.
  - زر إلغاء التحديد السريع.
- **إسناد فوري ومباشر من الصف**: يمكن للسوبر أدمن النقر مباشرة على اسم المسؤول في صف العميل لتغيير تعيينه فوراً.
- **الاحتفاظ بخيار التوزيع الجماعي بالعدد**: لا زال بإمكانك الضغط على زر "⚡ توزيع جماعي بالعدد" لتوزيع عدد معين (مثلاً 50 عميل) دفعة واحدة.

### 2. 💎 تصميم عصري وفاخر (Ultra-Premium SaaS Design)
- خط عربي فخم وحديث (**Cairo**) مع محاذاة RTL مثالية وتنسيق احترافي للأرقام والحقول.
- **مظهر ليلي (Dark Theme)** فخم كوضع افتراضي مع زجاجية بطاقات (Glassmorphism) وظلال ناعمة.
- **زر تبديل المظهر النهاري/الليلي (Dark / Light)** بنقرة واحدة من الشريط العلوي.
- بطاقات إحصائيات تفاعلية (KPI Cards) متوهجة توضح: إجمالي العملاء، المعيّنون، تم التواصل، الردود، التعاقدات.
- جدول تفاعلي ذكي فائق السرعة يدعم آلاف الصفوف بسلاسة تامة.
- أزرار روابط سريعة لفتح محادثة واتساب المباشرة 💬، زيارة الموقع 🌐، أو فتح حساب انستجرام 📷 للعميل بنقرة واحدة.

### 3. 🛠️ حل المشاكل الجذرية والتوافق السحابي الكامل
- **إزالة الاعتمادية المعطلة على Claude Sandbox**: كان الكود القديم يتطلب `window.claude` مما كان يجعله يتعطل فوراً خارج بيئة كلود.
- **محرك تخزين هجين فائق الذكاء (Hybrid DB Engine)**:
  - **الوضع المحلي (Offline Local Mode)**: يعمل تلقائياً وبشكل فوري بدون الحاجة لأي إعدادات مسبقة عبر `localStorage` مع مزامنة لحظية بين التبويبات عبر `BroadcastChannel`.
  - **الوضع السحابي (Firebase Live Sync)**: إمكانية تفعيل الربط السحابي في الوقت الفعلي عبر **Cloud Firestore** لمشاركة المنصة بين فريق العمل على مختلف الأجهزة والهواتف.
- **تسجيل دخول آمن**:
  - بوابة دخول منفصلة للسوبر أدمن لفك تشفير بيانات العملاء عبر كلمة المرور الماستر المشفرة بتقنيات `PBKDF2 + AES-GCM`.
  - بوابة دخول لفريق العمل بأسماء المستخدمين وكلمات المرور التي يحددها السوبر أدمن.
- **إزالة قيود المتصفح المزعجة**: تم التخلص من حظر النسخ وإخفاء الشاشة التلقائي (Blur) عند مغادرة الصفحة لتوفير تجربة عمل مرنة.

## 🚀 طريقة الرفع السريع على Vercel (خطوة بخطوة)

تم تجهيز المشروع بملف `vercel.json` وإعدادات `vite` ليكون متوافقاً 100% مع Vercel.

### الطريقة الأولى: الرفع عبر GitHub (الأسهل والموصى بها)
1. قم بإنشاء مستودع جديد (Repository) على حسابك في **GitHub**.
2. ارفع ملفات هذا المجلد إلى المستودع:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of Sales Dashboard v2"
   git branch -M main
   git remote add origin https://github.com/USERNAME/REPO_NAME.git
   git push -u origin main
   ```
3. افتح موقع **[Vercel](https://vercel.com)** وسجل الدخول.
4. اضغط على **"Add New..."** ثم **"Project"**.
5. اختر المستودع الخاص بك من القائمة.
6. سيتعرف Vercel تلقائياً على أن المشروع مبني بـ **Vite**.
7. اضغط على **"Deploy"** مباشرة بدون تعديل أي إعدادات!
8. مبروك! سيصبح موقعك متاحاً برابط سريع وآمن (`.vercel.app`).

### الطريقة الثانية: الرفع عبر أداة Vercel CLI
إذا كان لديك `vercel` مثبت:
```bash
npm install -g vercel
vercel
```
واتبع التعليمات البسيطة التي تظهر على الشاشة.

## 💻 التشغيل والتجربة محلياً (Locally)

لتشغيل الداشبورد على جهازك في بيئة التطوير:
```bash
# تثبيت الحزم (تم مسبقاً)
npm install

# تشغيل خادم التطوير المحلي
npm run dev
```
سيفتح لك الرابط فوراً على: `http://localhost:3000` أو `http://localhost:5173`.

لبناء النسخة الإنتاجية النهائية:
```bash
npm run build
```

## ☁️ إعداد الربط السحابي مع Firebase (اختياري لفريق العمل)

إذا كنت ترغب في أن يرى فريق المبيعات التعيينات لحظياً على هواتفهم وأجهزتهم:
1. ادخل على [Firebase Console](https://console.firebase.google.com/) وأنشئ مشروعاً مجانياً (Spark Plan مجاني 100%).
2. فعّل خدمة **Cloud Firestore** في وضع الـ Test Mode أو بقواعد أمان مناسبة.
3. من إعدادات المشروع (Project Settings)، انسخ بيانات الـ Web App (`projectId` و `apiKey`).
4. افتح الداشبورد كسوبر أدمن واذهب لتبويب **"إعدادات السحابة" (⚙️)**.
5. الصق البيانات واضغط **"تفعيل وربط فايربيز الآن"**.
6. يمكنك الضغط على **"نقل البيانات المحلية إلى السحابة"** لرفع جميع الحسابات والعملاء المنضمين دفعة واحدة!

## 👥 الصلاحيات والأدوار المتاحة (Roles)
- **سوبر أدمن (Owner)**: اطلاع كامل على كل الشيتات، تشفير وفك تشفير، إسناد العملاء، إدارة فريق العمل، إحصائيات المبيعات والتنفيذ.
- **سيلز (Sales)**: يرى فقط العملاء الموكلين إليه تحديداً، ويقوم بتحديث حالات التواصل (اتبعت / رد / معانا).
- **أقسام التنفيذ (SEO / ميديا / سوشيال / برمجة / UI)**: يرى العملاء الذين انضموا بنجاح ("معانا") لتحديث حالة القسم الخاص به (0 = لسه، 1 = شغال، 2 = خلص).
